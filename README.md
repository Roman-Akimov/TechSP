 ### Лабораторные работы по ТехСП.
 
 ЧитайГород - Онлайн-библиотека для чтения цифровых книг с сохранением прогресса,
избранным и real-time уведомлениями о новинках.

#### Стек
- Backend: FastAPI, SQLAlchemy, Pydantic, JWT
- БД: PostgreSQL
- Межсервисное взаимодействие: gRPC (Protocol Buffers)
- Очереди: RabbitMQ
- Real-time: WebSocket
- Прокси: Nginx
- Frontend: Jinja2 (HTML)

#### Архитектура
Клиент → Nginx → API Service → PostgreSQL
                              ├→ gRPC Service (рекомендации)
                              └→ RabbitMQ → Notification Service → WebSocket → Клиент

#### Роли
- **reader** — поиск, чтение, избранное, рекомендации
- **admin** — управление каталогом, статистика

#### Основной функционал
- Регистрация/вход (JWT)
- Поиск книг по жанрам, авторам, году
- Онлайн-чтение с сохранением страницы
- Избранное и история чтения
- Персональные рекомендации
- Уведомления о новых книгах

#### БД (основные сущности)
users, roles, books, genres, book_genres (M:N), favorites (M:N),
reviews, reading_progress

Роли пользователей:
**1. Пользователь (Читатель / reader)**
Эта роль предназначена для конечных потребителей контента платформы и включает следующий функционал:

· **Авторизация:** Пользователь может проходить процессы регистрации и входа в систему.

· **Навигация и поиск:** Читатель имеет возможность искать книги, используя фильтры по жанрам, авторам и году издания, а также просматривать подробную карточку выбранной книги.

· **Чтение и синхронизация:** Доступно онлайн-чтение цифровых книг, при котором приложение открывает текст с последней сохраненной страницы или с самого начала. По мере чтения или при выходе из книги система автоматически фиксирует текущую страницу и отправляет данные для сохранения индивидуального прогресса чтения в базе данных.

· **Управление избранным:** Читатель может нажать кнопку «Добавить в избранное» в карточке книги, после чего система сохранит её в профиле пользователя для быстрого доступа.

· **Персонализация:** При заходе на главную страницу читатель получает персонализированный список предложенных книг, который формируется отдельным рекомендательным микросервисом на основе истории прочитанного и добавленного в избранное.

**2. Администратор сервиса (admin)**
Эта роль предназначена для сотрудников, ответственных за управление платформой и её библиотечным фондом:

· **Авторизация:** Администратор также проходит процедуру регистрации и авторизации для входа в систему.

· **Управление каталогом:** Основная функция администратора заключается в наполнении и редактировании каталога, что включает в себя управление книгами, авторами и литературными жанрами.

· **Публикация контента:** Администратор работает в панели управления, где заполняет данные новой книги (название, файл, обложка, жанр) и подтверждает её добавление с сохранением в базу данных.

· **Запуск системы уведомлений:** Действия администратора по добавлению новых книг выступают триггером для системы: основной сервер публикует это событие в брокер сообщений RabbitMQ, что приводит к массовой рассылке уведомлений читателям в режиме реального времени.
